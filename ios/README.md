# Onpa Lab（iPhoneテストアプリ）

「通話しながら音楽を流して、声と音楽の音量を別々に変えられるか」をiPhoneで確かめるための小さなアプリです。

## 動かし方
1. Macで `ios/OnpaLab.swiftpm` をXcodeで開く（ダブルクリックでOK）
2. 部品（LiveKit）のダウンロードが終わるまで少し待つ
3. 上の実行先で自分のiPhoneを選ぶ（USBでつなぐか、同じWi‑Fi）
4. 「Signing & Capabilities」で Team に自分のApple IDを選ぶ
5. ▶︎（Run）
6. 初回はiPhoneの 設定 → 一般 → VPNとデバイス管理 で、自分のApple IDの開発元を「信頼」する

## 試すこと
- 曲を検索して再生 →「音楽」スライダー
- 1台目で「部屋を作る」→ 出てきた6桁の番号を2台目で入れて「入る」
- 通話中に「声」と「音楽」のスライダーを別々に動かす
